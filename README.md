# Potted History

A personal illustrated notebook. The homepage **is** the story — cartoon character cards, expandable arcs, attributed quotes. Not a product.

## Run it

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Write another history later

Edit files in the repo. There is no login and no editor app.

1. Duplicate `src/content/motley-court.ts`
2. Fill the same `History` shape (cast, CK3-ish traits, arcs, quotes)
3. Point `src/content/index.ts` at the new file

Portraits live in `public/portraits/`. Ink caricatures, not photos.
